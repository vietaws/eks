# PersistentVolumes

**Learning objective:** describe what a PersistentVolume is and how it relates to Pods.

"To keep data when a Pod dies, you need storage that lives at the *cluster* level, not the Pod level. That's a PersistentVolume."

## Demo

1. "No PVs yet — none have been provisioned."
   ```bash
   kubectl get pv
   ```
   Expected: empty (kind provisions PVs on demand when a PVC appears).

2. "PVs are cluster-scoped (not namespaced) — note there's no -n flag that matters."
   ```bash
   kubectl api-resources | grep -E 'persistentvolume'
   ```
   Expected: `persistentvolumes` is cluster-scoped; `persistentvolumeclaims` is namespaced.

3. "We'll see a PV appear automatically when we create a PVC next lesson."

**✅ Conclusions:**

- PV = cluster-level storage with its own lifecycle.
- Access modes + capacity + reclaim policy + StorageClass define it.
- Pods use a PVC to bind a PV. Next: PVCs and dynamic provisioning.
